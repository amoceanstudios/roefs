# AMOCEAN INTEL — meegeleverde vormgeving

- `amocean-night.webp`: gegenereerd fotografisch nachtbeeld van oceaan en natte rotsen, met hard flitslicht en analoge filmkorrel. Het is geen echte locatieopname. De oorspronkelijke generatie is voor deze interface gemaakt; dit bestand is als WebP gecomprimeerd zonder verdere visuele bewerking. Resolutie en compositie blijven behouden. De afbeelding is decoratief en bevat geen klantgegevens.
- `amocean-display.ttf`: ongewijzigde **Alfa Slab One**, Copyright 2016 The Alfa Slab One Project Authors, onder SIL Open Font License 1.1. De volledige meegeleverde licentie staat in [AMOCEAN-DISPLAY-OFL.txt](AMOCEAN-DISPLAY-OFL.txt). De CSS-familienaam `AmoceanScreen` is een alias; het fontbestand is niet aangepast.
- `amocean-mark.png`: bestaande merkafbeelding uit de aangeleverde applicatie.

Fontbron: https://github.com/google/fonts/tree/main/ofl/alfaslabone (opgehaald op 19 oktober 2026).
